# Capstone Trivia Quiz 🎯

This is a front-end trivia quiz web app built as part of my capstone project at Kenzie Academy. It fetches trivia questions from a public API, presents multiple-choice options, and provides instant feedback with scoring.

Recently, I extended this project to explore modern deployment and DevOps practices using **Azure Web Apps** and **Azure DevOps Pipelines**.

---

## 🧩 Features

- Trivia questions fetched dynamically from an API
- Multiple-choice answers with score tracking
- Highlights correct/incorrect selections
- Responsive and user-friendly design

---

## 🛠️ Tech Stack

- **HTML**  
- **CSS**  
- **JavaScript (Vanilla)**  
- **API Integration**: Open Trivia DB or similar  
- **DevOps Practice**: Azure Static Web Apps, Azure Pipelines (CI/CD)
